## 🐳 **Docker-Based RAG System Implementation Plan**

### **Architecture Overview**
```
Docker Containers:
├── backend (FastAPI + RAG Service + CodeLlama)
├── chroma (ChromaDB for embeddings)
├── db (PostgreSQL for metadata)
├── kafka (Message streaming)
└── ollama (Local LLM service)
```

---

## 📋 **Step-by-Step Docker Implementation Plan**

### **Phase 1: Docker Services Setup**

#### **Step 1: Add Ollama Service to Docker Compose**
1. **Update `docker-compose.yml`**
   - Add Ollama service
   - Configure network connectivity
   - Set up volume persistence for models

2. **Ollama Service Configuration**
   ```yaml
   ollama:
     image: ollama/ollama:latest
     container_name: ollama_server
     ports:
       - "11434:11434"
     volumes:
       - ollama_data:/root/.ollama
     environment:
       - OLLAMA_HOST=0.0.0.0
     networks:
       - app_network
     deploy:
       resources:
         reservations:
           memory: 4G
   ```

3. **Add Volume**
   ```yaml
   volumes:
     ollama_data:
   ```

### **Phase 4: RAG Consumer Implementation**

#### **Step 5: Create RAG Consumer**
1. **File: `server/consumers/raw_log_to_rag_consumer.py`**

2. **Docker-Specific Configuration**
   ```python
   # Environment variables for Docker
   CHROMA_HOST = os.environ.get("CHROMA_HOST", "chroma")
   CHROMA_PORT = os.environ.get("CHROMA_PORT", "8000")
   OLLAMA_HOST = os.environ.get("OLLAMA_HOST", "ollama")
   OLLAMA_PORT = os.environ.get("OLLAMA_PORT", "11434")
   MODEL_CACHE_PATH = "/app/models"
   ```

3. **Consumer Features**
   - Subscribe to `raw_logs` Kafka topic
   - Process logs in batches
   - Group by `source_id` (source-based chunking) *IMPORTANT STEP*
   - Collect for 1 hour and then generate embeddings using `all-mpnet-base-v2`
   - Store in ChromaDB with metadata of that hour

4. **Chunking Strategy**
   - **Source-based chunks**: Group all logs from same source
   - **Time windows**: Within each source, group by time (1-hour windows)
   - **Size limits**: Max 1000 logs per chunk
   - **Chunk ID format**: `source_{source_id}_chunk_{timestamp}_{index}`

### **Phase 5: RAG Service Implementation**

#### **Step 6: Create RAG Service**
1. **File: `server/services/rag_service.py`**

2. **Docker Service Connections**
   ```python
   class RAGService:
       def __init__(self):
           self.chroma_client = chromadb.HttpClient(
               host="chroma", 
               port=8000
           )
           self.ollama_client = ollama.Client(
               host=f"http://ollama:11434"
           )
           self.embedding_model = SentenceTransformer(
               'all-mpnet-base-v2',
               cache_folder='/app/models'
           )
   ```

3. **Service Components**
   - ChromaDB client (HTTP connection to chroma container)
   - Ollama client (HTTP connection to ollama container)
   - Embedding model (cached in `/app/models/`)
   - Query processing pipeline
   - Response generation
